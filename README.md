# Customer Churn Analysis

## Tugas Hands-On 3: Pandas Lanjutan

### Ringkasan Kasus

Kasus yang dipilih adalah Customer Churn Analysis pada sektor telekomunikasi. Proyek ini bertujuan untuk mengolah dan menganalisis data pelanggan guna mengetahui faktor yang berkaitan dengan pelanggan berhenti berlangganan (churn).

### Temuan

Berdasarkan hasil pengolahan dan analisis data, diperoleh tiga temuan:

1. Status Pelanggan: Terdapat 2.819 pelanggan aktif dan 2.181 pelanggan churn.

2. Jenis Kontrak: Pelanggan dengan jenis kontrak Bulanan memiliki persentase churn tertinggi.

3. Tagihan Bulanan: Rata-rata tagihan pelanggan churn sebesar Rp271.059,92, sedangkan pelanggan aktif sebesar Rp276.342,69.
